# 🎨 User Profile Card Generator

A modern full-stack web application that allows users to create stylish digital ID cards by entering their details. The application sends data from the frontend to the backend using POST requests and dynamically displays beautiful profile cards.

---

## 🚀 Features

* 📝 Form-based user input
* 👤 Create multiple profile cards
* 🖼️ Profile image support using image URLs
* 📍 Dynamic location display
* 🏢 Company name section
* 🌙 Modern attractive UI
* 💳 ID-card style design
* ✨ Hover animations
* 📱 Responsive layout for laptop and mobile
* 🔄 Backend communication using POST requests
* ⚡ Built with Node.js and Express

---

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/profile-card-generator.git
```

### Move into the project folder

```bash
cd profile-card-generator
```

### Install dependencies

```bash
npm install
```

### Start the server

```bash
node server.js
```

---

## 🌐 Open in Browser

```
http://localhost:5000
```
